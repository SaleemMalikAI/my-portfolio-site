# Saleem Malik · Portfolio

Personal portfolio of Saleem Malik, AI Full Stack Engineer. Live at [saleem-malik.vercel.app](https://saleem-malik.vercel.app).

Built with Next.js (App Router), TypeScript and Tailwind CSS. Light and dark mode, static export of a single page.

## Development

```bash

npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

## Editing content

All text (experience, projects, skills, education, contact links) lives in
[`portfolio/src/data/profile.ts`](portfolio/src/data/profile.ts). The photo and resume are in `public/`.

## Deployment

Deployed on Vercel from the `portfolio/` directory. Pushing to `main` deploys production; other branches get preview URLs.
